Готовый комплект FitSim с первой иллюстрацией упражнения.

Установите файлы из архива в одну папку приложения, сохранив структуру папки images.
Картинка уже подключена для «Отжимания широким хватом» и «Отжимания с узкой постановкой рук».
Она появляется в разделе «Тренировка» → «Создать тренировку» → «Грудные».

Чтобы добавить следующие изображения: положите их в images/exercises и добавьте точную пару «название упражнения: путь» в exercise-images.js.
